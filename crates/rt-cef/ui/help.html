Riptide

Modes

Like vim, keys mean different things in different modes. The status bar shows the current mode.

normal: keys run commands (j scrolls, f hints, : opens the command line). Unbound keys other than letters and digits reach the page.

insert: keys go to the page. Entered by focusing a text field or i; Escape leaves.

command: typing a command after :. Tab completes, Up/Down walk history, Return runs it.

hint: labels on links and buttons; type a label to act on it. Escape cancels.

passthrough: every key goes to the page until Shift-Escape. Entered with Ctrl-v.

prompt / yesno: answering a question (dialogs, downloads, logins, permissions) shown above the status bar.

Commands

Run with :. Chain with ;;. A count before a key (3j) is passed to its command.

Key bindings

Your current bindings, per mode. Change them with :bind / :unbind or in your config; changes from the defaults are marked.

Hints

f labels clickable elements; type a label to click it. F opens a link in a new tab, ;b in a background tab, ;y yanks it, ;d downloads it, ;r keeps going for several links.

Labels use hints.chars. The general form is :hint [--rapid] [group] [target], with groups all, links, images, inputs.

Configuration

Files load in this order, later ones winning: autoconfig.toml (written by :set/:bind), config.toml, config.lua. :config-source reloads them. Run riptide --paths to find the directory, or see version.

# config.toml
hints.chars = "asdfjkl"
tabs.pinned.frozen = true

[bindings.normal]
"<Ctrl-x>" = "tab-close"
d = ""            # remove a default binding

Lua

config.lua is Lua 5.4. c.hints.chars = "asdf" sets options; rt.get, rt.bind(keys, command [, mode]), rt.unbind, rt.platform, rt.config_dir are available, and require loads files from the config directory.

For editor completion, save riptide --lua-types as rt.meta.lua in the config directory.

if rt.platform == "macos" then c.hints.uppercase = true end
rt.bind("<Ctrl-e>", "mode-leave", "insert")
